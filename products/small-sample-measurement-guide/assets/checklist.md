# 数字を書く前のチェックリスト

## 数と期間

- [ ] 何本 (何件) の記録かを書いた
- [ ] 何日間 (いつからいつまで) の記録かを書いた
- [ ] 平均だけでなく、中央値や一番多い・少ない値も見た

## 段階

- [ ] 結果を「仮説 / 暫定 / 記述」のどれかに分けた
- [ ] 数が少ない間は「仮説」にした
- [ ] 「効いた」「効かない」と言い切る言葉を使っていない

## 関係と原因

- [ ] 関係 (一緒に起きた) と原因 (それのせいで起きた) を分けて書いた
- [ ] 時間帯・話題・曜日など、ほかの違いが混ざっていないかを確かめた
- [ ] 1回の結果で書き方の決まりを作っていない

## 記録

- [ ] 0の結果も記録に残した
- [ ] 数字をどこから写したか (管理画面・分析ツールなど) を書いた
- [ ] 推定した数字を、観測した数字と混ぜていない

## 比べる

- [ ] 比べる2つは、条件をそろえて何本かずつ試してから比べる
- [ ] 条件がそろうまでは、記録をためることに集中する
