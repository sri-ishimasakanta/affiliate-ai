# 「今の状態」レポートのテンプレート

AIと長く開発を続けると、会話や作業の区切りごとに「どこまで終わって、何が本番で動いているか」
を確かめ直す必要があります。このテンプレートは、その確認を毎回同じ形で残すためのものです。
各項目には「値」「出どころ」「確かめた時刻」を必ず書きます。

## 1. 概要

- 今のフェーズ:
- 最後に完了したフェーズ:
- 次に始めるフェーズ (前提が満たされているか):
- 止めるべき問題 (あれば最初に書く):

## 2. 事実 (値・出どころ・確かめた時刻)

| 事実 | 値 | 出どころ | 確かめた時刻 | 鮮度 |
|---|---|---|---|---|
| 本番のデータベースの版 | | 本番を読んだ | | 今観測した / 記録から読んだ |
| 本番で有効な機能 | | 実行の設定を読んだ | | |
| 定期実行の状態 | | スケジューラを読んだ | | |
| テストの結果 | | 手元で実行した | | |

## 3. 出どころの強さ (強い順)

1. 今観測した本番の状態
2. 実行に使っている設定
3. 記録 (実行の履歴・ログ)
4. ドキュメント・メモ

強い出どころと弱い出どころが食い違ったら、強い方を採り、食い違いを「ずれ」として書きます。

## 4. ずれ

| ずれ | 強い出どころの値 | 弱い出どころの値 | どう扱うか |
|---|---|---|---|
