# 変更の記録

## 0.2.0

- ファイルと生成物の承認を中身の hash で固定する原則を追加: チェックリストに「3. ファイルと生成物の承認を固定する」(5 項目) を足し、25 項目にした。手引きに承認の流れ (提出・承認・使う前の照合・変わったら承認し直す・履歴・事後の承認) と落とし穴 (同じパスの上書き・古い承認の使い回し) を足した。
- 設定の例に、画像・添付の承認 (中身の hash・写しの保存・公開前の照合) と承認の履歴の設定を足した。
- 利用の条件 (license.md) を足した。1 回の購入で、購入者本人と、所属する 1 つの組織・チームの中での業務利用まで (書き換えた社内用の手順書の共有を含む)。
- 人の確認 (H4 の前の読み取り) を受けて直した: 手引きの中で保証に読める言い切りの 2 文を、何がしやすくなるかの書き方に直した。段階の置き方 (A〜E は安全さの順ではない。迷ったら C か E) を直した。hash の短い説明を足した。チェックリストの計測の項目を、承認の状態を区別して記録する項目に替えた (25 項目のまま)。設定の例がツールの設定ファイルではないことを書いた。
