# Threads Trend Intelligence (T6.5) — 計画 (まだ始めていない)

T6.4 の後の次の大きなフェーズ。**まだ実装していない。** ここに書くのは、人と合意した範囲だけ。

## 目的

BizFluxLab 自身の投稿の成績と、Threads 全体で伸びている投稿の形を比べ、次の投稿づくりへの
**提案** を出す。最初は提案だけで、自動で生成の設定を変えない。

## 範囲 (合意した拡張計画)

- **自分の投稿の特徴の保存 (feature store)**: 公開ごとに、トピック・きっかけ (hook)・CTA・長さ・
  構成・時刻・メディア・リンク・テーマ・種類 (通常記事 / Growth Post) と、保存済みの指標。
- **外の Threads を読むだけで観察する**: For You・トレンドのトピック・検索・カスタムフィード。
- **伸びた投稿の検出**: いいね・返信が多い投稿 (breakout)。投稿者のふだんの水準 (author
  baseline) と比べて、どれだけ抜けているか。
- **トピック以外の特徴の抽出**: hook / CTA / 長さ / 構成 / 時刻 / メディア / リンク / テーマ。
- **反応の速さ** (engagement velocity): 安全に観察できる範囲だけ。
- **外の形 × BizFluxLab の結果**: 外で伸びている形が、自分の投稿でも効いているか。
- **まずは提案だけ** (recommendation-only)。**少ない数からの自動調整はしない。**
- 十分な数と人の判断がそろってから、**制御された形で** 生成に戻す (後のフェーズ)。
- 実装の方向: 夜の定期の観察は **Playwright** を第一の候補にする。

## してはいけないこと

- 読むだけ。**いいね・返信・フォロー・再投稿・DM の自動化はしない。**
- 観察のために自分のアカウントで操作しない (見るだけ)。
- 少ない数の結果で、生成・公開の設定を自動で変えない。
- 秘密 (token・cookie・パスワード) を記録や報告に残さない。
